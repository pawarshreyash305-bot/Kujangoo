# 🛒 Kujangoo - Django E-Commerce Website

Kujangoo is a full-stack e-commerce web application built using Django and Python.

It provides an online shopping experience with product browsing, categories, user accounts, shopping cart functionality, reviews, profile management, and Razorpay payment integration.

## 🚀 Features

- 👤 User registration and login
- 📧 Custom user authentication using email
- 📱 Phone number-based user information
- 🛍️ Product listing and product details
- 🗂️ Product categories
- 🛒 Shopping cart
- ➕ Increase/decrease cart quantity
- ⭐ Product reviews
- 👤 User profile
- 🖼️ Profile image upload
- 💳 Razorpay payment integration
- 📦 Order/payment workflow
- 🔐 Environment variables for sensitive credentials
- 📱 Responsive e-commerce interface

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- Razorpay
- Pillow
- python-dotenv
